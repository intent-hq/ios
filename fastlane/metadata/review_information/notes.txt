Thank you for reviewing Intent Companion.

WHAT THE APP IS
Intent Companion is a local-network companion app for the Intent desktop application, a developer tool that orchestrates AI coding agents. The iOS app connects directly to the Intent daemon running on the user's own computer over the local network. There is no hosted backend and no account system — pairing happens device-to-device using a QR code (or manually entered credentials), secured by TLS certificate fingerprint pinning and a bearer token.

NO DEMO ACCOUNT
Because the app has no account system, no demo account can be provided. Full functionality requires the Intent desktop app running on a computer on the same network as the review device.

HOW TO EXERCISE THE FULL FLOW
The Intent desktop app for macOS is available for download at https://intentapp.dev. To see the full paired experience: download and install it on a Mac on the same network as the review device, launch it, then open its settings to display the pairing QR code and scan it with this app. The app then connects to the daemon on that Mac and shows the paired experience described below.

WHAT YOU WILL SEE WITHOUT A DAEMON ON YOUR NETWORK
The following applies if you choose not to install the desktop app.
1. On first launch the app shows the pairing screen with two options: "Scan QR Code" and "Manual Connection".
2. "Scan QR Code" asks for camera permission and opens a camera view prompting "Point at the QR code in Intent Settings". The QR code is displayed by the desktop app; without one, nothing scans and the sheet can be dismissed.
3. "Manual Connection" opens a form with Host, Port (default 5181), and API Token fields. Submitting values without a reachable daemon shows a clear "Connection failed" error and the form stays usable — no crash, no hang.
4. All app content (workspaces, notes, tasks, agent conversations) appears only after pairing with a daemon.

WHAT THE PAIRED EXPERIENCE LOOKS LIKE
The attached screenshots show what the app looks like after pairing. After pairing, the app shows a workspace list — each workspace is a coding project with a title, status, and repository name. Opening a workspace shows its detail view with the agents working in it and its notes. Selecting an agent shows the agent's conversation: the user's messages and the agent's responses. Notes open as documents with headings and task checklists whose items can be checked off from the phone. There is no content beyond this — the app is a read/monitor/respond companion for work happening on the user's own computer.

PERMISSIONS
The app requests camera access solely to scan the pairing QR code, and local network access solely to connect to the user's own daemon.
